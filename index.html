# Research Agent — Reason + Act
def react_loop(query, max_steps=5):
    state = {"query": query, "context": []}
    for step in range(max_steps):
        # 1. Reason: What to do next?
        thought = llm.reason(state)
        if thought.is_final():
            return thought.answer()
        # 2. Act: Execute tool
        result = execute_tool(thought.tool(), thought.args())
        # 3. Observe: Add to context
        state["context"].append({"thought": thought, "result": result})
    return synthesize(state)

Multi-step reasoning with tool calling. Each loop: Think → Act → Observe.

Used in: Research AgentAvg steps: 3.2
⚡ Tool Calling + Retries Resilience 
# Tool execution with retry + fallback
def call_with_retry(tool, args, max_retries=3):
    backoff = [0.5, 1.0, 2.0]  # exponential
    for attempt in range(max_retries):
        try:
            return tool(args)
        except TimeoutError:
            sleep(backoff[attempt]); continue
        except APIError as e:
            if attempt == max_retries - 1:
                return fallback_tool(args)
            sleep(backoff[attempt])
    return {"error": "All retries failed", "fallback": True}

Exponential backoff + fallback tools. Zero failures surface to user.

Recovery rate: 94%Max wait: 3.5s

# Short-term + Long-term memory
class AgentMemory:
    def __init__(self):
        self.short_term = []      # session context
        self.long_term = PostgresStore()  # persistent
    def add(self, event, importance):
        self.short_term.append(event)
        if importance > 0.7:
            self.long_term.store(event)
        if len(self.short_term) > 10:
            self.summarize()

Research Report Pipeline
Django · Tavily · Groq · fpdf2 · Job queue with retry/cancel
A Django web app that turns any research topic into a structured PDF report. Tavily fetches 5 live sources, Groq Llama 3.3 70B synthesizes findings into sections, and fpdf2 generates the final document. Built the frontend with Tailwind — no Streamlit, no LangChain. If Groq fails, Gemini catches it. Jobs run in a queue so users can retry or cancel.
Why Django over Streamlit: I wanted a real web app with user accounts, job history, and cancel buttons — not a demo script.
Fallback logic: Groq timeout → exponential backoff → Gemini swap. No user-facing failures in 200+ runs.

MCP is the emerging standard for agent tool integration. I've built MCP servers and integrated them with LangChain agents.

Agent ↔ MCP Server ↔ Tools 
# MCP Server for Research Agent
from mcp import Server, Tool

server = Server(name="research-agent")

@server.tool()
def search_web(query: str) -> List[Dict]:
    """Tavily search with MCP standard"""
    return tavily_search(query)

@server.tool()
def synthesize(sources: List[Dict]) -> str:
    """LLM synthesis via Groq"""
    return groq_completion(sources)
